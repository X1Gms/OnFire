# OnFire 🔥

## About

OnFire is an Android mobile application developed to help users track their physical activities and keep an eye on their fitness goals.

The application focuses on activities such as running, walking and cycling. It also includes a calorie counter to help users monitor their physical activity.

The project was developed using Java and Android Studio as part of my mobile development learning journey.

## Main Features

- Track physical activities.
- Support for activities such as running, walking and cycling.
- Calorie counter.
- Mobile application designed for Android.

## Technologies

- **Java** – Main programming language.
- **Android Studio** – Android development environment.
- **Firebase Authentication** – Authentication integration.
- **Firebase Realtime Database** – Database integration.
- **Firebase Analytics** – Application analytics.
- **osmdroid** – OpenStreetMap integration.
- **Gradle** – Build automation.

## Getting Started

### Requirements

- Android Studio.
- Java 11.
- Android SDK.
- A Firebase project.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/X1Gms/OnFire.git
   ```

2. Open the project in Android Studio.

3. Configure the Firebase project and its Android configuration file.

4. Sync the Gradle dependencies.

5. Run the application using an Android emulator or a physical Android device.
